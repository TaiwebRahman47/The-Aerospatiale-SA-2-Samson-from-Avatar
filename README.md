Aerospatiale-SA-2-Samson-Design-Catia-V5

This repository contains my CAD design of the Aerospatiale SA-2 Samson twin-ducted-fan VTOL utility aircraft, created as part of the IPE410 CAD/CAM Sessional course. The project involved developing a detailed 3D model of the ducted-rotor aircraft, widely recognized for its versatile role in light utility transport, heavy lifting, and close air support operations.
